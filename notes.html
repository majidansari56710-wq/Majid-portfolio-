Chapter 1: Introduction to Computer (Full Notes)

1. Introduction

A computer is an electronic device that accepts data from the user, processes it according to instructions, stores it, and produces meaningful information. It performs millions of calculations in a very short time and is widely used in education, business, hospitals, banks, industries, research, and communication.

2. Definition of Computer

A computer is an electronic machine that accepts data as input, processes it according to a set of instructions, stores it, and gives the desired output as information.

3. Data and Information

  • Data: A collection of raw facts and figures that have no meaning by themselves. (Example: 50, Majid, 98%)
  • Information: Processed and meaningful data. (Example: "Majid scored 98% in the examination.")

4. IPO Cycle (Input-Process-Output)

A computer works on the IPO cycle:

Input → Process → Output → Storage
  • Input: Data is entered into the computer using input devices (Keyboard, Mouse, Scanner).
  • Process: The CPU processes the input data.
  • Output: The processed result is shown through output devices (Monitor, Printer, Speaker).
  • Storage: Stores data for future use.

5. Characteristics of a Computer

  • Speed: Works extremely fast, performing millions of operations per second.
  • Accuracy: Gives accurate results if input instructions are correct.
  • Storage: Stores a huge amount of data.
  • Automation: Works automatically once a program starts.
  • Diligence: Never gets tired or bored.
  • Reliability: Gives consistent and dependable results.
  • Versatility: Can perform many different tasks.

6. Basic Parts of a Computer

  • Input Unit: Used to enter data (Keyboard, Mouse, Scanner).
  • CPU (Central Processing Unit): Brain of the computer. Contains ALU, CU, and Registers.
  • Memory Unit: Stores data (RAM, ROM, Cache).
  • Output Unit: Displays information (Monitor, Printer, Speaker).
