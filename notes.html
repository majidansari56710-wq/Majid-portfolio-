Part 1

Functional Units of a Computer

A computer consists of four main functional units:

Input Unit ➔ CPU (ALU, CU, Registers) ➔ Output Unit | Memory Unit

1. Input Unit

Accepts data and instructions from the user and converts them into machine-readable binary form.

  • Functions: Accepts data ➔ Converts into binary ➔ Sends to CPU.
  • Examples: Keyboard, Mouse, Scanner, Microphone, Webcam, Joystick, Touch Screen.

2. Central Processing Unit (CPU)

The CPU is called the brain of the computer because it controls and performs all processing tasks.

A. ALU (Arithmetic Logic Unit): Performs arithmetic operations (+, −, ×, ÷) and logical operations (>, <, =, AND, OR, NOT).

B. Control Unit (CU): Controls and coordinates all parts of the computer and manages data flow.

C. Registers: Very small and fast memory locations inside the CPU used to store temporary data.

3. Memory Unit

Stores data, instructions, and intermediate/final results.

4. Output Unit

Displays processed information in human-readable form.

  • Examples: Monitor, Printer, Speaker, Projector, Plotter.

Part 2

Memory, Hardware and Software

1. Memory Classification

Memory is divided into Primary Memory and Secondary Memory.

RAM (Random Access Memory): Temporary (volatile) memory used to store data currently being processed. Cleared when power is off.

ROM (Read Only Memory): Permanent (non-volatile) memory storing startup (booting) instructions.

Cache Memory: Extremely fast memory located inside/near the CPU to store frequently used data.

3. Types of Software

  • System Software: Manages hardware and runs application software (Examples: Windows, Linux, Android).
  • Application Software: Performs specific user tasks (Examples: MS Word, MS Excel, Chrome).

Exam Corner

Important Viva & Exam Questions

Q1. Why is the CPU called the brain of the computer?

Because it controls and performs all processing tasks and coordinates all operations.

Q2. Why is SSD faster than HDD?

SSD uses electronic microchips (flash memory) with no moving parts, while HDD relies on mechanical spinning platters.

Chapter 1: Introduction to Computer (Full Notes)

1. Introduction

A computer is an electronic device that accepts data from the user, processes it according to instructions, stores it, and produces meaningful information. It performs millions of calculations in a very short time and is widely used in education, business, hospitals, banks, industries, research, and communication.

2. Definition of Computer

A computer is an electronic machine that accepts data as input, processes it according to a set of instructions, stores it, and gives the desired output as information.

3. Data and Information

  • Data: A collection of raw facts and figures that have no meaning by themselves. (Example: 50, Majid, 98%)
  • Information: Processed and meaningful data. (Example: "Majid scored 98% in the examination.")

4. IPO Cycle (Input-Process-Output)

A computer works on the IPO cycle:

Input → Process → Output → Storage
  • Input: Data is entered into the computer using input devices (Keyboard, Mouse, Scanner).
  • Process: The CPU processes the input data.
  • Output: The processed result is shown through output devices (Monitor, Printer, Speaker).
  • Storage: Stores data for future use.

5. Characteristics of a Computer

  • Speed: Works extremely fast, performing millions of operations per second.
  • Accuracy: Gives accurate results if input instructions are correct.
  • Storage: Stores a huge amount of data.
  • Automation: Works automatically once a program starts.
  • Diligence: Never gets tired or bored.
  • Reliability: Gives consistent and dependable results.
  • Versatility: Can perform many different tasks.

6. Basic Parts of a Computer

  • Input Unit: Used to enter data (Keyboard, Mouse, Scanner).
  • CPU (Central Processing Unit): Brain of the computer. Contains ALU, CU, and Registers.
  • Memory Unit: Stores data (RAM, ROM, Cache).
  • Output Unit: Displays information (Monitor, Printer, Speaker).
