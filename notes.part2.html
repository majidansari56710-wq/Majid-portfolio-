Part 1

Functional Units of a Computer

A computer consists of four main functional units that work together synchronously to process data into information.

1. Input Unit ➔ 2. CPU (Processing) ➔ 3. Output Unit | 4. Memory Unit

1. Input Unit

Accepts raw data & instructions from users and translates them into machine-readable binary form before transferring them to the CPU.

  • Functions: Accepts data ➔ Converts to binary ➔ Sends to CPU.
  • Examples: Keyboard, Mouse, Scanner, Microphone, Webcam, Joystick, Touch Screen.

2. Central Processing Unit (CPU)

Known as the brain of the computer because it controls, regulates, and executes all operations.

Core Components of CPU:

A. ALU (Arithmetic Logic Unit): Performs arithmetic operations (+, −, ×, ÷) and logical operations (>, <, =, AND, OR, NOT).

B. Control Unit (CU): Acts as the supervisor. Manages data flow between CPU, memory, and I/O devices.

C. Registers: High-speed internal CPU memory locations used to store temporary data and instructions during processing.

3. Memory Unit

Stores data, system instructions, and intermediate/final processing results.

4. Output Unit

Receives binary processed results from CPU and translates them into human-readable visual/audio formats.

  • Examples: Monitor, Printer, Speaker, Projector, Plotter.

Part 2

Memory, Hardware & Software

1. Memory Classification

Memory is categorized into Primary (Main) and Secondary (Auxiliary) storage.

RAM (Random Access Memory): Volatile, high-speed, read/write memory storing active running applications. Data clears when powered off.

ROM (Read Only Memory): Non-volatile, permanent memory containing startup (Booting) instructions (BIOS).

Cache Memory: Ultra-fast, expensive memory situated near/inside the CPU to store frequently accessed data.

3. Software Types

  • System Software: Manages hardware and provides a base platform (e.g., Windows, Linux, macOS, Android).
  • Application Software: Performs specific user tasks (e.g., MS Excel, Photoshop, VLC).

Exam Corner

Important Viva & Exam Questions

Q1. Why is the CPU called the brain of the computer?

Because it controls all hardware components, directs memory operations, and executes all logical & mathematical tasks.

Q2. Why is SSD faster than HDD?

SSD uses electronic microchips (Flash Memory) with no moving parts, whereas HDD relies on mechanical spinning platters.
